# Synthetic CPU smoke results — NOT a language-model benchmark

These plots and CSVs were generated by executing `compare_ngpt.py smoke` on CPU.
They are not OpenWebText results and are not evidence of an nGPT speedup. The GPT
baseline learns this tiny cyclic-transition task faster in this run. See
`../../TEST_REPORT.md` for the testing boundary and exact configuration.

Replot without retraining, from the project root:

```bash
python compare_ngpt.py plot --out example_results/synthetic_cpu --smooth 5
```

The two `run.json` files and `synthetic_data_metadata.json` preserve the original
settings and data fingerprints. The original synthetic token files and model
checkpoints are not bundled.
